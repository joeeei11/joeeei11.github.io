05 / BEHIND THE WORK

代表项目：序章。

把分散的求职准备工作，组织成从简历整理到面试复盘的本地工作流。

要解决的问题
简历、岗位信息、面试记录和复盘建议分散在不同工具中，难以形成可执行、可追溯的准备流程。
我的工作
用 Tauri、Rust 和 Leptos 构建本地桌面应用；实现简历版本管理、AI 面试、投递记录、题库管理和 SQLite 数据持久化。
技术与结果
兼容 Claude、OpenAI、DeepSeek 等模型；业务数据本地保存，API Key 进入 Windows Credential Manager，形成可从源码运行的完整应用。
